1. **Отбор** — `src/navigator/composition/composer.py`, промпт `composition-prompt/0.6.0`. Выбирает 2–3 карточки и пишет только внутренние поля:

2. **Написание** — **новый** файл `src/navigator/composition/writer.py`, промпт `card-writer-prompt/0.2.0`. Один вызов на каждую выбранную карточку, все параллельно (ThreadPoolExecutor). Пишет все шесть пользовательских полей:
   - `title`;
   - `main_idea`;
   - `applied_insight`;
   - `reflection_question`;
   - `question_explanation`;
   - `perspective` («Подробнее»).

   Главная инструкция — эталонный голос и метод «проверь каждое предложение вслух». Описание из корпуса передаётся с пометкой «учёным языком — слова не переносить».
3. **Проверки каждой написанной карточки** — `check_card`:
   - контракт `Perspective` (M3.1 / M3.2);
   - `amplification_hits`;
   - неназванные чувства и специалисты, только в полях, обращённых к человеку;
   - ложная точность (номера глав, стихов, `§`, `N:N`);
   - метаязык в «Подробнее»;
   - «в нём» или «в его пользу» во втором вопросе.

   Упавшая карточка переписывается **одна**, с причиной отказа, до 3 попыток. Если всё равно не прошла — она **не показывается**: остаются две, и `fewer_than_three_reason` заполняется автоматически.
4. **`compose()`:**
   - принимает `writer=`;
   - если композер вернул только отбор, работает двухшаговый путь `compose_written`;
   - если вернул старый формат с текстом (тестовые заглушки), собирает результат как раньше;
   - в `meta.usage["writer"]` пишутся `seconds`, `cards` (попытки, причины, вызовы), `dropped`, `selection`.
5. **Писатель вызывается с `--effort medium`**: так в `src/navigator/prototype/server.py` задан `ClaudeCodeCLIWriter`. Отбор и формулировка вопроса — с уровнем по умолчанию.

## 4. Решения, которые нельзя случайно откатить

1. Двухшаговая композиция: отбор отдельно, написание по карточке параллельно. Отбор **не пишет** пользовательский текст.
2. Язык применяется ко всем шести полям одним промптом писателя.
3. Предложенный вопрос не больше 3 предложений — **контракт**, а не просьба.
4. Проверки — только надёжные структурные. Никакого чёрного списка обычных слов («участвовать», «происходящее», «верный», «смысл» не запрещены).
5. Карточка, которую не удалось написать чисто, **не показывается** (остаются 2), а не показывается «черновик».
6. Писатель опирается **только** на данные карточки — правило 7 в `WRITER_PROMPT`. Причина: в прогоне до этого правила писатель добавил из памяти модели сюжетные подробности, которых нет в корпусе: мать и няня у Эпиктета I.11, старейшины у Моисея, «имена записаны на небе» у Луки 10. После правила в пробе их нет.
7. Копия включает «Что имеется в виду?» и «Подробнее».
8. Писатель — `--effort medium`; отбор и интерпретация — по умолчанию.
9. Из M3.3 остаются:
   - READY = 0, цитаты не показываются;
   - `quote_for_card` — единственный путь цитаты;
   - SOURCE `disabled_pending_full_fragment_text`;
   - понятные ссылки (`references.py`).
10. Не трогались: корпус, taxonomy, embeddings, benchmarks, код retrieval.

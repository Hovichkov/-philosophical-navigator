# ASSET MAP — стартовая карта материалов и интеллектуальных активов
## Для первичной инвентаризации Kimi

**Статус:** рабочая карта, а не полный каталог.  
**Назначение:** показать масштаб и структуру уже существующих активов до продуктовых выводов.

> Важно: этот документ не задаёт будущий продукт и не утверждает, что перечисленные проекты следует продолжать или монетизировать в нынешнем виде. Это карта того, что уже существует или было существенно разработано. Во время аудита нужно дополнять её по мере изучения исходных материалов и самостоятельно искать активы, которые здесь не замечены.

- философия и история идей;
- религиозные и духовные традиции;

- публичная лекция и семинар;

## 4. Метод анализа литературного героя / курс «Разбор героя»

Существует разработанный практический метод чтения литературного произведения через устройство героя.

Текущая структура метода включает шесть действий:

1. Персона.
2. Повтор.
3. Тень.
4. Рана / комплекс.
5. Другой.
6. Изменение героя.

В основе — психоаналитическое / юнгианское чтение, но метод предназначен не только для специалистов. Его задача — дать человеку переносимый способ самостоятельно разбирать героя и текст.

Более ранняя формулировка продукта/метода: «Как разбирать любую книгу по Юнгу».

Рабочий принцип анализа:

**наблюдение → гипотеза → интерпретация → проверка текстом.**

В методическом поле также присутствуют:

- Эго;
- Персона;
- Тень;
- комплексы;
- проекции;
- архетипические функции;
- символы;
- трансформация героя.

### Уже существующий образовательный материал

Для курса используются / разработаны материалы по произведениям:

- «Семейное счастие»;
- «Марья Моревна»;
- «Василиса Прекрасная»;
- «Муму»;
- «О мышах и людях».

«Семейное счастие» используется также как финальная практика.

Формат курса разрабатывался как:

- модули;
- видео;
- PDF workbook / рабочая тетрадь;
- практические задания;
- ответы / обратная связь;
- Telegram как среда проведения.

Этот актив следует рассматривать отдельно как:

- уже созданную методологию;
- существующий учебный контент;
- потенциально готовый или почти готовый продукт;
- интеллектуальную собственность, которую можно применять не только в одном курсе.

## 5. Philosophical Navigator / «Инструмент Самоанализа»

Отдельный существенно разработанный цифровой гуманитарный проект.

### Идея

Инструмент помогает человеку посмотреть на собственный вопрос через разные философские различения.

Это:

- не терапия;
- не диагностика;
- не советчик;
- не система, которая сообщает человеку «как правильно жить».

Базовый принцип:

**представление пользователя → философское различение → применение к его ситуации → новый вопрос к себе.**

Система предлагает несколько философских перспектив на один вопрос.

### Корпус

Собран большой исходный корпус — первоначально более 1000 цитат/кандидатов.

В рабочей версии существует существенно меньший проверяемый слой карточек / источников, по которому проводится строгая верификация прямых цитат.

В корпус входят или прорабатываются:

- Бхагавад-гита;
- Коран;
- Дао дэ цзин;
- Чжуан-цзы;
- Лунь юй / Конфуций;
- Дхаммапада;
- ранние буддийские сутты;
- Упанишады;
- досократики;
- Платон;
- Эпиктет — «Энхиридион»;
- Эпиктет — «Беседы»;
- Эпикур — «Письмо к Менекею»;
- Эпикур — «Главные мысли»;
- другие философские / религиозные тексты по мере развития корпуса.

Для источников важен принцип:

**сначала источник → затем интерпретация.**

Цитаты проверяются по конкретным переводам и снабжаются точными ссылками.

### Состояние продукта

Есть работающий локальный MVP / прототип, прошедший несколько итераций.

Уже существенно разработаны:

- концепция;
- taxonomy;
- retrieval;
- архитектура карточки;
- язык ответа;
- правила против навязывания интерпретации;
- UX первого круга;
- несколько сотен автоматических тестов;
- корпусная инфраструктура.

Этот проект представляет собой одновременно:

- самостоятельный цифровой продукт;
- структурированный философский корпус;
- накопленную методологию работы с жизненными вопросами;
- исследование способов переводить философские тексты в современный понятный язык.

При коммерческом аудите нельзя автоматически считать, что лучший способ использовать этот актив — запускать именно существующее приложение.

## 14. Уже существующие способы превращения одного материала в другой

В работе уже используются или разрабатываются процессы:

### Радио → статья
Расшифровка / эфир превращается в самостоятельный письменный материал.

### Радио → short / reel
Из длинного эфира извлекаются короткие самостоятельные идеи.

### Лекция → книга
Лекционные расшифровки проходят сверку, редакторский отбор и превращаются в авторские главы / статьи.

### Лекция → образовательный модуль
Авторская методика оформляется в последовательность занятий и workbook.

### Источник → философская карточка
Первичный философский текст проходит верификацию, интерпретацию и превращается в структурированную перспективу для Navigator.

Эти pipeline сами являются активом: они снижают стоимость создания нового продукта из старого материала.

Это следует учитывать как отдельный актив: накоплена не только информация, но и частично формализованный способ превращать исследование в узнаваемый авторский текст.

# 18. Что Kimi должен сделать с этой картой

Эта карта — **индекс, а не вывод**.

Во время дальнейшей работы:

1. Проверяй каждый пункт по исходным материалам.
2. Исправляй неточности, если документы им противоречат.
3. Дополняй карту новыми активами.
4. Отмечай дубли и пересечения.
5. Различай:
   - **А — уже существует;**
   - **Б — получается простой переработкой;**
   - **В — требует существенного создания с нуля.**
6. Отдельно отмечай:
   - активы с уже существующей аудиторией;
   - активы с подтверждённым опытом продаж;
   - активы, которые можно продавать повторно;
   - активы, требующие постоянного присутствия автора;
   - активы, которые можно масштабировать;
   - права / ограничения на переиспользование.
7. Ищи то, чего нет в этой карте: её задача — помочь увидеть массив, а не ограничить исследование.

**Пока не делай продуктовых выводов только на основании этой карты.**

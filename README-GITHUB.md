# Philosophical Navigator — облачная разработка

Python-прототип «Инструмент Самоанализа». Запускайте команды из корня клона.
Корпус по умолчанию — compact (124 карточки, 113 доступны поиску).
Финальный корпус включается явно, в тестовом режиме.

## Структура

- `src/navigator/` — CLI, поиск, интерпретация, композиция, сервер и HTML-интерфейс.
- `data/corpus/` — compact, манифест и редакторские данные.
- `corpus/final-2026-10-07/` — полный неизменяемый финальный пакет, включая манифест SHA256; сохранять байт-в-байт.
- `data/retrieval-layer/` — поисковый слой v1 Block 1 для final/B.
- `data/corpus-full/` — legacy-корпус для full и диагностики final/C.
- `data/quotes/` — инвентарь готовности цитат compact.
- `data/eval/benchmarks/`, `tests/` — benchmark и автоматические проверки.
- `Источники/`, выбранные корневые документы и два файла `Архив/CORPUS-LAUNCH-124-…` — исходники для импорта, восстановления и проверок.
- `reports/`, кеши, локальные handoff-документы и архивы передачи остаются только локально.

## Установка

Нужен Python 3.11 или новее. Установка для работы из исходников:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pip install torch sentence-transformers
```

`torch` и `sentence-transformers` нужны реальному поиску, но пока не объявлены
в `pyproject.toml`. Lock-файла нет: точная воспроизводимость версий пока не обеспечена.
Обычная установка wheel отдельно от дерева проекта не проверена: данные корпуса
лежат вне Python-пакета. Используйте клон и editable-установку выше.

До запуска сервера отдельно загрузите закреплённую ревизию модели при доступной сети
(это существенная загрузка, не обязательная для редактирования кода):

```sh
python -c 'from huggingface_hub import snapshot_download; from navigator.providers.embeddings import LOCAL_EMBEDDING_CONFIG as c; snapshot_download(repo_id=c.model, revision=c.revision)'
```

Код использует BAAI/bge-m3, ревизия `5617a9f61b028005a4858fdac845db406aefb181`.
Сервер устанавливает `HF_HUB_OFFLINE=1`: пустой кеш на новом компьютере не подойдёт.
Веса и пересоздаваемые embedding-кеши не включаются в Git.

Также нужен отдельно установленный и авторизованный `claude` CLI в PATH.
Интерпретатор, отбор, writer и валидатор вызывают его через subprocess.
Доступность настроенной в коде модели зависит от учётной записи и среды.
Токены и авторизацию с Mac в репозиторий не копировать.

## Запуск

```sh
source .venv/bin/activate
navigator prototype --no-browser --port 8770
```

Финальный корпус с текущим retrieval layer и пулом 20:

```sh
navigator prototype --corpus final --final-mode B --retrieval-layer v1-block1 --pool-size 20 --no-browser --port 8770
```

Адрес: `http://127.0.0.1:8770/`. Сервер привязан к loopback.
В облачной IDE используйте приватное перенаправление порта 8770.
Это прототип без встроенной пользовательской авторизации; не открывайте порт публично.
Сессии и ошибки записываются в исключённую из Git папку `reports/`.
Игнорирование Git не удаляет эти данные с диска облачной машины.

## Проверки

Истории и вопросы в тестах созданы владельцем проекта или с помощью ИИ.
Владелец разрешил их публичную публикацию. Оригинальные тесты и фикстуры
включены без изменения, в том числе:

- `tests/fixtures/m3_2_reference_cases.json`;
- `data/eval/interpretation/m2_6-interpretation-benchmark-v0.1.json`;
- `tests/test_m3_prototype.py`, `tests/test_m3_3_1_human_language.py`, `tests/test_m2_6_interpretation.py`.

Блокер отсутствующих фикстур и импортируемого тестового модуля устранён.
Локальные сессии и отчёты в `reports/` по-прежнему исключены: проверки записанных
прогонов, рассчитанные на их наличие, могут пропускаться или не получать примеров.
Это не подтверждение прохождения полного набора тестов в облачной среде.

Пример отдельных проверок без модели:

```sh
python -m pytest -q tests/test_sources_and_corpus.py tests/test_final_corpus_import.py tests/test_retrieval_layer_v1.py
```

При подготовке переноса тесты и модели не запускались. Полный набор включает
тест локальной модели, который может загрузить её в память, если веса уже есть в кеше.

## Ограничения облака и Git

- Нужны сеть для первичной установки/загрузки и доступа Claude CLI, достаточные RAM и диск.
- На Linux без доступного MPS текущий код выбирает CPU; ответы могут быть медленнее Mac.
- В headless-среде авторизация CLI и приватное перенаправление порта требуют настройки.
- Локальный репозиторий создан, origin настроен на `https://github.com/Hovichkov/-philosophical-navigator`. Commit, push и публикация при подготовке не выполнялись.
- `.gitignore` защищает обычное добавление новых файлов; `git add -f` его обходит,
  а уже отслеживаемые файлы он не исключает. Не добавляйте исключённые файлы принудительно.
- Поиск типовых секретов не доказывает их полного отсутствия. Перед первым коммитом
  проверьте staged diff; секреты храните в настройках облачной среды.

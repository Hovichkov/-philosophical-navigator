# Retrieval Layer — отдельный поисковый слой финального корпуса

Слой хранит **поисковые тексты** карточек. Его видит только семантический поиск.
- Не является частью проверенного корпуса и ничего в нём не меняет: цитаты, `philosophical_move`, CSV и манифест остаются прежними.
- Не попадает в карточку пользователя, в отбор и в writer.

## v1 / Block 1 (2026-10-08)

Файл: `RETRIEVAL-LAYER-v1-BLOCK1.csv` — 199 строк.
- Бхагавад-гита — 40;
- Упанишады — 95;
- Дао дэ цзин — 64.

| Колонка | Содержание |
|---|---|
| `card_id` | ID карточки в `FINAL-CORPUS-ACTIVE-v1.csv` |
| `block`, `work`, `location` | для чтения человеком |
| `distinction` | какое различение делает фрагмент (по проверенной цитате и ходу мысли) |
| `situation` | одно предложение: какой **тип** человеческой ситуации это различение освещает (общий, не применение к конкретному вопросу) |
| `retrieval_text` | `distinction` + `situation` — то, что идёт в поиск |
| `layer_version` | `retrieval-layer/v1-block1` |
| `basis` | на чём основан текст: цитата + ход мысли или только цитата (у резервных карточек ход мысли — ярлык) |

**Как используется.** Только финальный корпус, режим B. Поисковый документ карточки = `retrieval_text` + проверенная цитата; у остальных 768 карточек — прежний «ход мысли + цитата».
- Включено по умолчанию: `navigator prototype --corpus final --final-mode B`.
- Выключить: `--retrieval-layer none`.
- Код: `src/navigator/representations/retrieval_layer.py`.

**Как заменить.** Новая версия — новый файл и новая версия в `LAYERS`. Версия входит в ключ кэша эмбеддингов, поэтому векторы разных версий не смешиваются.

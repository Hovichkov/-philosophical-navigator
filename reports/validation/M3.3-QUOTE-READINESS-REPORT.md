## Главный вопрос

> Можем ли мы прямо сейчас показывать пользователю дословную цитату из этой карточки без галлюцинации?

**Ответ: нет, ни для одной карточки.**

| категория | карточек | что значит |
|---|---|---|
| **READY** | **0 / 113** | дословный русский отрывок найден в **локальном** полном тексте источника, точная ссылка, известен перевод |
| **PARTIAL** | **66 / 113** | в данных проекта есть отрывок-кандидат, ссылка и перевод известны, но сверить отрывок с изданием нечем |
| **NOT_READY** | **47 / 113** | отрывка в данных нет, или текст / атрибуция помечены как нерешённые |

## Почему READY = 0

1. **В проекте нет ни одного полного текста источника.**
   - `Источники/*.md` — списки кандидатов с пересказом («Ядро», «Perspective»), а не тексты изданий.
   - Реестр `filosofskiy-korpus-istochniki.md` называет переводы и даёт **онлайн-ссылки**: djvu.online, lib.ru, РГБ, dhamma.ru, ancientrome.ru.
   - Реестр сам пишет: «Перед превращением каталога в полностью локальный полнотекстовый корпус требуется отдельно закрыть три позиции» — Дхаммапада Топорова, Энхиридион Тыжова, «Беседы» Тароняна.
   - Папки `data/sources/` (место, где аудит ищет локальные тексты) нет.
2. **Отрывки из поля `thought` (67 карточек) есть только в рабочем файле проекта** `Архив/CORPUS-LAUNCH-124-v1-final-textual-pass.md`.
   - Этот файл сам предупреждает: поле Thought «still requires insertion of a short verbatim excerpt from the approved Russian edition».
   - Кто и по какому изданию вставил эти отрывки, в данных не записано. Сверить их с изданием локально нечем.
   - По правилу M3.3 такой отрывок нельзя показывать как проверенную цитату: он может быть точным, а может быть восстановлен по памяти.
3. **Ссылка у карточки часто — диапазон, а не место цитаты.**
   - У 37 из 67 отрывков ссылка карточки — диапазон, например «Бытие 27:1–40».
   - Точный стих или параграф самого отрывка не записан.
   - Цитата требует точной ссылки.

## Что сделано в коде (подготовка, без показа пользователю)

- **Контракт проверенной цитаты** `VerifiedQuote` (`src/navigator/models/quote.py`). Провенанс записывает:
  - `method = local_source_match`;
  - путь к локальному файлу в `data/sources/`;
  - sha256 файла;
  - позиции символов;
  - переводчика и издание.
- **`verify_quote`** перечитывает локальный файл и проверяет:
  - хеш;
  - что по записанным позициям стоит ровно этот текст.
  Файл вне `data/sources/`, изменённый или отсутствующий файл — отказ.
- **`quote_for_card`** — единственный путь цитаты в результат: только строка инвентаря с категорией READY, и только если цитата заново прошла проверку.
- **Модель не может быть источником цитаты.** В её схеме ответа нет поля цитаты. Лишние поля её ответа (`quote`, `verified_quote`, `source`) код не читает. Это проверено тестом.
- **Пользователю цитаты не показываются.** READY = 0, поэтому поле всегда пустое. В интерфейсе цитаты не выводятся.
